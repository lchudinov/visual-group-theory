# Subgroups

## Overview

A subgroup is a some smaller group living inside a large group.

## Regularity

Group D3. `frf = r^(-1)`

The following fragment permeates throughout the diagram.

![rfr fragment](<3.1 frf fragment.png>)

`frfr = e` the path `frfr` always brings you back to where you started.

The algebraic relations of a group, like `frf = r^(-1)`, give Cayley diagrams a uniform
symmetry - every part of the diagram is structured like every other.

![D3](<3.1 D3 Cayley diagram.png>)

`frfr = e` `f^2 = e` `r^3 = e`

A diagram is called a regular if it repeats every one of its interval patterns throughout 
the whole diagram, the sense described above.

Every Cayley diagram is regular. Diagrams lacking regularity do not represent groups(so they are not called Cayley diagrams).

## Subgroups

When one group is contained in another, the smaller group is called a subgroup of the lager group.
If H is a subgroup of G, we write `H < G` or `H <= G`

Orbits are subgroups, moreover, they are cyclic subgroups.

Orbit of r in D3 `<r> = {e, r, r2} < D3` => `C3 < D3`

### Example D3

Orbits are:
`<e> = {e}`
`<r> = {e, r, r2}`
`<f> = {e,f}`
`<rf> = {e, rf}`
`<r2f> = {e, r2f}`

### Yet one more example Z6

`Z6 = {0,1,2,3,4,5}`

Subgroups are: `{0}`, `<2> = {0, 2, 4}`, `<3> = {0, 3}`, `<1> = Z6`

## A (terrible) way to find all subgroups

How to find all subgroups of a given group G of order n:
 0.   {0} and G are always are subgroups 
 1.   Find all subgroups generated by a single element (cyclic subgroups)
 2.   Find all subgroups generated by two elements
 n-1. Find all subgroups generated by n-1 elements
