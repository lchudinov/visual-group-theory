## An Example D4 cosets

![D4 Cosets](<3.2 D4 Cosets.png>)

If H is a subgroup of G, then a (left) **coset** is a set
  `aH = {ah : h \in H}`
where `a \in G` is some fixed element. The distinguished element (in this case, *a*),
that we choose to use to name the coset is called the **representative**.

In a Cayley diagram, the left coset aH can be found as follows: start from a node *a*
and follow all paths in *H*.

For example, let H = <f> in D3. The coset {r, rf} H is the set `rH = r<f> = r{e, f} = {r, rf}`

Alternatively, we could ave written (rf)H to denote the same coset, because
`rfH = rf{e, f} = {rf, rf2} = {rf, r}`

![Cosets in D3](<3.2 Cosets in D3.png>)

## Formal definition of cosets

For any subgroup `H <= G`, the union of the (left) cosets of H is the whole group G.

Right cosets:
  `Ha = {ha : h \in H}`
  
the right cosets of `H = <f>` in D3 are 

`Hr = <f>r = {e,f}r = {r,fr} = {r,r2f}` (recall `fr = r2f`)

`<f>r2 = {e, f}r2 = {r2, fr2} = {r2, fr}`

left cosets are different

`rH = r<f> = r{e, f} = {r, rf}`
`r2H = r2<f> = r2{e, f} = {r2, r2f}`

## Left vs right cosets

![Left vs right cosets](<3.2 Left vs right cosets.png>)

Left and right cosets are generally different.

If `H < G` then the index of H in G, written [G : H], is the number of distinct left(or equivalently, right) cosets of H in G.
